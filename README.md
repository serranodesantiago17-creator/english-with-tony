# English with Tony

Sitio gratuito de inglés avanzado (C1) adaptado al TOEFL ITP: 20 temas de gramática, vocabulario y lectura con ejercicios autocorregibles y explicaciones en español.

- El sitio completo está en `index.html`.
- Los contenidos editables están en `fuente/`; después de editarlos ejecuta `python3 build.py`.
- Consulta `GUIA_PUBLICACION.md` para el contador de visitas (GoatCounter).
